## Output network and the chip boundary

**The chip boundary is `RFOUT`** (`design/README.md`: "`RFOUT` is the off-chip match boundary"). On the **chip** side: the DUT only -- its output array and `Lchoke`, `Cblock`, `Cin`. **Off** chip: the sense source `Vbsense`, `Lmatch`, `Cmatch`, `Vlsense` and the 50 ohm load. Every off-chip element is ideal and lossless.

```
COLL --[Cblock 100p, ON CHIP]-- RFOUT |boundary| --[Lmatch]--+--[Rl 50]
                                                              |
                                                           [Cmatch]
                                                              |
                                                             GND
```

**Element values are derived, not tuned to a result.** The resistance is the load-line record's own array-independent quantity for the nominal row -- `vswing_v / iq_per_nx_a` = 0.4 / 0.0015 = 266.6667 ohm per Nx -- over the array **this netlist has** (14 devices x Nx=10 = 140 Nx), giving **Ropt = 1.9048 ohm at the collector**. Source: `sim/device-npn13g2/records/20261107-125027-93cf5ae.loadline.json`, cell `supply_nominal_v 0.8` / `tolerance nominal` / `swing_mode saturated`. That record's own `nx_needed.load_ohm_ideal` (2.5157 ohm) is **not** used: it is the load for the 106-Nx array the study *recommends*, not the array benched here.

- `Q = sqrt(50/Ropt - 1)` = 5.0249; `Cmatch = Q/(w0 Rl)` = 6.5506 pF; `Lmatch = (Q Ropt + 1/(w0 Cblock))/w0` = 0.6663 nH.
- `Cblock` is **-0.6518 ohm** reactive at f0, 34 % of Ropt, so it is **absorbed in closed form** into `Lmatch` (0.6239 nH L-section + 0.0425 nH for `Cblock`), which is why the **collector**, not `RFOUT`, sees a real Ropt. `Lchoke` (+j1534 ohm in shunt at `COLL`) perturbs Ropt by 0.12 % and is left alone.
